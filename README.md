## Lanzamiento Oficial de Phantom OS 🚀

Herramienta de utilidad avanzada para MU Online enfocada en **rendimiento, estabilidad y capacidad Stealth**.

### Características Principales:
* **Zoom Engine Avanzado:** Capacidad de extender la cámara más allá de los límites normales, con función automática para **"Mantener"** el zoom (Re-aplicación automática tras Warps o cambios de mapa).
* **Auto-Potas Stealth:** Motor indetectable a nivel hardware (SendInput). No usa ventanas simuladas, engañando a LiveGuard y otros Anti-Cheats.
* **Combo Cíclico Dinámico:** Sistema inteligente de ultra-baja latencia que se dispara únicamente al mantener presionado tu **Control Izquierdo**.
* **Optimizaciones de Motor (0% CPU):** Hilos auto-regulables que duermen el procesador durante tiempos inactivos.
* **Modo Camuflaje (Ghost Mode):** Oculta el proceso para evadir escaneos y no ser capturado por tu software de grabación (OBS).

### ¿Cómo Instalar?
1. Descarga el archivo `Phantom-OS.exe` desde la sección de **Assets** más abajo.
2. Ejecútalo (Windows solicitará permisos de Administrador para acceder a la memoria del juego de forma segura).
3. Selecciona tu cliente de MU (`main.exe`) en la lista y presiona **Inyectar**.
